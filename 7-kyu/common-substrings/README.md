<h2><a href=https://www.codewars.com/kata/5669a5113c8ebf16ed00004c/train/javascript target="_blank">Common Substrings</a></h2><h3>7 kyu</h3><p>Given 2 strings, your job is to find out if there is a substring that appears in both strings. You will return <code>true</code> if you find a substring that appears in both strings, or <code>false</code> if you do not. We only care about substrings that are longer than one character. Substrings are case-insensitive, e.g. <code>"aB"</code> and <code>"Ab"</code> should compare equal in this kata.</p><h3 id="examples">Examples:</h3><pre><code class="language-java"><span class="cm-string">"Something"</span>, <span class="cm-string">"Fun"</span>  <span class="cm-operator">==&gt;</span> <span class="cm-atom">false</span><span class="cm-comment">// because "something" and "fun" contain no common substrings</span><span class="cm-comment">// (We do not count the 'n' as a substring in this Kata,</span><span class="cm-comment">// because it is only 1 character long)</span><span class="cm-string">"Something"</span>, <span class="cm-string">"Home"</span> <span class="cm-operator">==&gt;</span> <span class="cm-atom">true</span><span class="cm-comment">// because both of the strings contain the substring `"me"`</span><span class="cm-comment">// (so**ME**thing and ho**ME**).</span></code></pre>
